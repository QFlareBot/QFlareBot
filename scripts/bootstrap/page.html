  1. Workers Scripts — Edit
  2. Workers KV Storage — Edit
  3. D1 — Edit
  4. Workers R2 Storage — Edit
  5. Account Settings — Read
  6. Workers 构建配置（Workers Builds Configuration / Workers CI）— Edit：第 ④ 步用它自动检测仓库连接、写构建配置
  7. 账户范围：所有账户

② 名称与可选项

Worker 名留空用默认 qqbot，KV 与 D1 沿用该名；已存在同名资源会直接复用。R2 填 none 表示不启用。
QQ 机器人不用在这里填：部署完、绑好自定义域名后，到面板「设置」里用手机 QQ 扫码创建，或填入已有机器人的 AppID / AppSecret。
