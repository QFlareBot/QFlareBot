# 配置 QQ 开放平台

::: tip
QQ 开放平台的界面偶尔会改版，下面的菜单名以 2026-09 为准。对不上时，找名字相近的菜单即可。
:::

## 1. 先确认凭证已保存

如果引导时填了 AppID / AppSecret，或者扫码新建了机器人，凭证已经存好了，跳过这一步。

否则先用自定义域名打开面板，到「设置」里填写 AppID 与 AppSecret 并保存；没有机器人的话点「扫码创建机器人」，用手机 QQ 扫码即可新建，凭证会自动保存。

**必须先保存凭证再填回调地址**：凭证没保存时 Worker 不会回应平台的校验请求，平台会报校验失败。

## 2. 登录并找到机器人

打开 [q.qq.com](https://q.qq.com)，用手机 QQ 扫码登录，在应用管理里点进你的机器人。扫码新建的机器人也在这里。

进入 **开发管理**，核对这里的 AppID 和面板「设置」里的是否一致。

## 3. 填写回调地址

<!-- 截图：回调配置页，填好请求地址、勾选事件的样子 -->

1. 打开 **回调配置**（也可以直接访问 <https://q.qq.com/qqbot/#/developer/webhook-setting>）。
2. 回调地址填面板概览页复制来的地址，即 `https://bot.example.com/webhook`。
3. 在 **添加事件** 里全部勾选。没有插件处理的事件，框架会直接忽略，多勾没有坏处；少勾了对应的消息就收不到。
4. 点确定保存。平台会立刻向这个地址发一次校验请求，没有提示“校验失败”就说明配好了。

Webhook 模式不需要配置 IP 白名单（已实测：回调校验、被动回复、主动消息都不依赖白名单）。

## 4. 把测试群加进沙箱

<!-- 截图：沙箱配置页，添加测试群与单聊成员 -->

机器人**发布上线之前**，只能在沙箱里添加的群和单聊成员中使用。

1. 打开 **沙箱配置**。
2. 添加一个你用来测试的 QQ 群，再添加要私聊测试的 QQ 号。
3. 把机器人拉进这个测试群。

然后回到[快速部署 · 试一下](./deploy#_4-试一下)，在测试群里 @机器人 发 `/echo 你好`。

## 5. 发布上线

在沙箱里测试没问题后，在平台 **首页** 找到 **发布流程**，按平台要求提交审核。审核通过后，机器人就能被其他群和用户添加了。

## 常见问题

**保存回调地址时提示校验失败**

- 填成了 `*.workers.dev` 的地址：QQ 访问不到，换成自定义域名。
- 域名刚绑上，证书或 DNS 还没生效：等几分钟，浏览器能打开面板后再保存。
- 面板里没有保存凭证，或者保存的 AppSecret 不是这个机器人的（比如在平台上重置过密钥）：到面板「设置」重新保存。
- 路径写错：应该是 `/webhook`。

**校验通过了，但机器人没反应**

- 事件没勾全：回到回调配置，把事件全部勾上。
- 测试群不在沙箱里：上线前只有沙箱里的群能用。
- 群里没有 @机器人：没开通“接收群内全部消息”的机器人只收得到 @ 它的消息。
- 看面板概览页的「最近事件」：有这条消息说明回调是通的，问题出在插件；完全没有记录说明平台没推过来，回头检查上面几条。
